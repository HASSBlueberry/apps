# BlueberryFaygo Home Assistant add-ons

Add `https://git.crit.rip/BlueberryFaygo/apps` to Home Assistant under Settings, Apps, App Store, Repositories.

BlueberryProxy provides LAN DNS, proxying and discovery. BlueberryQuantum manages gateway providers. BlueberryQDB discovers Android phones and supplies runtime App Check tokens to Blueberry MyQ.
