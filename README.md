# BlueberryFaygo Home Assistant add-ons

Add `https://git.crit.rip/BlueberryFaygo/apps` to Home Assistant under Settings, Apps, App Store, Repositories.

BlueberryProxy provides LAN DNS, proxying and discovery. BlueberryQuantum manages gateway providers. BlueberryQDB supplies the ADB and App Check API. BlueberryDroid deploys Android on a separate SSH server and provides its ingress UI.
