Use a password or a private key. You can install the generated public key below in the server account's authorized_keys. Uploaded keys and passwords are stored privately in this app's persistent data.





Compare the fingerprint with the server's SSH host key before saving it. It is checked again on every connection.




The server install runs as a system service and survives SSH interruptions. Stopping tracking leaves that service running. Deploy resumes tracking a saved job.

Install MyQ
Install the signed MyQ APK from a direct HTTPS download, an APKMirror bundle you downloaded, or an authorized USB phone. The API verifies the package and Chamberlain signing certificate before installation. Existing app data is retained.
