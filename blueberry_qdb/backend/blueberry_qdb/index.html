Native MyQ controller

This mode uses the signed-in app directly. It needs no Chrome login, access token, OAuth secret or App Check token.


Checking and saving do not press the control. Choose the actual door button, not a menu. HASS commands will inspect the current screen, verify the reported door state, and use this control once. Unknown states, changed controls and pending commands are refused.

After saving, add Blueberry MyQ in Home Assistant and choose Use the signed-in MyQ app through BlueberryQDB. Submitting that form checks the connection immediately.

Bridge connection settings

Supervisor discovery supplies these automatically. For manual setup, use the app's network hostname with port 8091 and its connection key.

Advanced cloud OAuth and App Check

The cloud mode is separate from the native controller and requires its own OAuth session. Native mode does not need these steps.
