BlueberryQDB

Connect and authorize Android through ADB. BlueberryQDB persists App Check and can exchange a manually captured MyQ OAuth callback. Configure optional login recovery and IMAP in the app Configuration tab.

OAuth and App Check renewal

OAuth tokens are stored and rotated by this bridge. Create a PKCE sign-in URL, complete MyQ sign-in, then paste the complete com.myqops://android?... callback. The bridge exchanges it using its current App Check token. The token API can then sync credentials to BlueberryQ.

Optional email login recovery
Configure MyQ email/password and a TLS IMAP mailbox before enabling recovery. Only new verification messages from MyQ for that login attempt are used. Recovery takes at most three minutes and stops on an unrecognized screen. The phone must be unlocked. No logout is required.
